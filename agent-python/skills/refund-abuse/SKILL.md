# 恶意退款/退款滥用调查 SOP

## 适用场景
- 单账号/单收货地址退款率显著高于基线
- 「仅退款」订单集中出现，或退款理由高度雷同
- 退货包裹掉包（退货商品与订单不符）、恶意索赔运费险

## 调查步骤
1. **固定主体**：提取账号/手机号/收货地址/支付账户，确认时间窗与订单范围。
2. **事件面核查**：检索退款相关客诉与风控工单，统计退款频次、金额分布、理由集中度。
   - 工具：`ticket_query`（customer_name=主体，query_type=售后/退款类事件，limit=20）
3. **业务面核对**：查订单与退款金额曲线，识别「下单即退款」「大额高频」「跨账号同地址」模式。
   - 工具：`sales_query`（query_type=按客户，period=近30天）
4. **情报佐证（可选）**：如工具目录中存在外部情报检索类工具，检索同手法恶意退款团伙情报；没有则跳过。

## 结论标准
- **malicious**：退款模式异常（高频/雷同理由/掉包证据）且跨订单稳定复现
- **suspicious**：退款率偏高但存在合理解释（尺码问题品类、质量批次问题）
- **benign**：退款行为与商品问题批次/正常售后周期吻合

## 处置建议模板
- malicious → 限制退款通道（需人工审批）+ 订单风控前置审核；同地址/支付账户关联账号并案排查
- suspicious → 该账号退款单转人工审核，观察 14 天
- benign → 放行，工单归档
