# 促销羊毛/刷单团伙识别 SOP

## 适用场景
- 大促/补贴活动中优惠券被批量领取核销
- 单个地区/产品销量短时异常激增
- 监控发现同设备/同收货地址的多账号下单

## 调查步骤
1. **圈定异常面**：先确认异常的范围（哪个产品/地区/活动），建立基线对比。
   - 工具：`sales_query`（product/region=线索指向的对象，period=活动期间，对比上一周期）
2. **事件反查**：检索相关工单与风控事件，找出集中出现的账号、设备、IP 特征。
   - 工具：`ticket_query`（product=涉及产品，status=open，limit=20）
3. **团伙特征放大**：用工单/事件里的集中字段（地区、产品）扩大检索，识别一机多号/一层多号模式。
   - 工具：`ticket_query`（region=集中地区；再用 customer_name=已识别账号逐一反查）
4. **手法情报比对**：检索外部情报确认是否为已知羊毛党/刷单团伙手法（工具链、代理池、接码平台）。
   - 工具：`youcom_search`（query=「羊毛党/刷单 + 涉及活动/平台」，freshness=oneMonth）

## 结论标准
- **malicious**：多账号共享设备/地址/支付特征 + 行为时间高度聚集 + 情报证实同手法团伙
- **suspicious**：单一维度异常（如销量激增）但无法串联出团伙结构
- **benign**：激增可由正常促销/市场因素解释

## 处置建议模板
- malicious → 冻结涉事优惠资格 + 拦截待核销券 + 输出账号名单转人工批量处置（需人工审批）
- suspicious → 收紧活动规则（加验/限量），对集中特征做标记观察
- benign → 放行，记录基线供后续对比
