⚠ 背景设计的第一原则是「不干扰内容」：聊天区是长时间阅读文字的场景， 高对比度或高频运动的背景会引起视觉疲劳。下方每个方案都标注了可读性等级： ✓ 低干扰 可直接用于聊天区；△ 中干扰 建议仅用于登录页/欢迎页；✗ 高干扰 只适合作装饰性场景。 请务必点开「叠加样例」逐一验证。

① 纯 CSS 方案 — 零 JS，性能最优

只靠 CSS 渐变与 keyframes，无 canvas、无逐帧计算，即使低端设备也几乎无开销。

② Canvas 方案 — 需 JS，效果更强

有逐帧绘制开销。已做 devicePixelRatio 适配、页面不可见自动暂停、粒子数按宽度自适应；落地时可再按需降密度。

③ 方案横向对比

用于最终决策：可读性、性能、实现成本、适用场景。
